Quadratic Equations & Complex Roots

Core Theory & Vieta's Theorem Estimated: 15 Mins

A quadratic equation is a second-order polynomial in variable $x$:

ax² + bx + c = 0, where a ≠ 0

The roots are given by the quadratic formula derived via completing the square:

x = (-b ± √(b² - 4ac)) / 2a

The Discriminant (D = b² - 4ac):

  • D > 0: Two distinct real roots.
  • D = 0: Exactly one real root (coincident, x = -b/2a).
  • D < 0: Two complex conjugate roots.

If $\alpha$ and $\beta$ are the roots of $ax^2 + bx + c = 0$, what is the exact value of: (1 / α²) + (1 / β²)

Sum of roots α + β = -b/a and product αβ = c/a.
(1/α²) + (1/β²) = (α² + β²) / (αβ)² = [(α + β)² - 2αβ] / (αβ)².
Substituting: [(-b/a)² - 2(c/a)] / (c/a)² = (b² - 2ac) / c².
